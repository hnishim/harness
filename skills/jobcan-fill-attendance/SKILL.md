# ジョブカン勤怠入力

ジョブカンのWeb画面を Browser で操作する。対象はユーザー本人の勤怠だけとし、勤務日には勤務場所 `from Home`、不足する打刻には出勤 `0900`（9:00）・退勤 `1800`（18:00）を補完する。ユーザーが明示的に別の値を指定した場合は、その指定を優先する。

## 1. 対象月を決める

日本時間の日付で判定する。

- 月末7日間（`day >= その月の日数 - 6`）なら当月を対象にする。
- 月初7日間（`day <= 7`）なら先月を対象にする。
- それ以外、またはユーザーの指示が当月・先月のどちらとも読めない場合は、対象月を質問して停止する。
- ユーザーが特定月を明示した場合は、この自動判定より優先する。

対象月と対象日付の範囲を作業開始前に短く示す。

## 2. ログインして出勤簿を開く

1. `https://id.jobcan.jp/users/sign_in?app_key=atd` を開く。30分でセッションが切れる前提で、既存ログイン状態を仮定しない。
2. ログインが必要なら、ユーザーに Cloud Browser 内で手動ログインしてもらう。認証情報をチャットに求めたり、入力したりしない。
3. 勤怠管理の出勤簿画面を開き、対象年月であること、ユーザー本人の画面であることを確認する。

## 3. 日ごとの確認と補完

対象月の初日から末日まで、日付を飛ばさず順に処理する。画面表示から休日区分、勤怠状況、出勤時刻、退勤時刻を確認してから操作する。

### 休業日

次のいずれかなら休業日として扱う。

- `休日区分` が `公休`、`法休`、`祝日`
- `勤怠状況` が `リフ`、`有休` など、勤務しないことが明白な状態

休業日では出勤時刻・退勤時刻がともに空欄か確認する。両方空欄なら変更せず次の日へ進む。いずれかが入力済みなら、意図しない勤怠変更のおそれがあるため、その日付・表示値を示してユーザーに確認を求め、全処理を停止する。

### 勤務日

1. 出勤簿を表示し、対象日をクリックしてその日の詳細を開く。
2. `Select when Work from Home` ドロップダウンで `from Home` を選び、`保存` をクリックする。保存完了の表示または選択値の反映を確認する。
3. 出勤時刻と退勤時刻を確認する。既にある時刻は変更しない。空欄の項目だけを次の手順で追加する。

#### 打刻の追加

1. 対象日をクリックし、表示されるメニューから `打刻修正` を開く。
2. 空欄の打刻種別に対応する入力欄を選ぶ。出勤なら `0900`、退勤なら `1800` を、`時刻` フィールドに半角4桁で入力する。
3. `打刻` をクリックする。
4. `打刻一覧` に、正しい日付・打刻種別・時刻で追加されたことを確認する。種別を選ぶUIや表示が画面上で判別できない場合は、推測で打刻せずユーザーに確認する。
5. 元の出勤簿に戻り、追加した項目が反映されていることを確認してから次の日へ進む。

## 4. 管理者承認

すべての対象日の補完が済んでから、`管理者ページ (ユーザー名)` を開き、`未承認打刻` の `X件` を開く。

一括承認の前に、一覧を確認する。

- 対象はユーザー本人で、今回この実行で追加した対象月の打刻だけでなければならない。
- 他の月・日付・利用者・既存の未承認打刻が混在する場合、全件選択や一括承認を行わない。対象外の状況を示してユーザーに判断を求める。
- 件数が今回追加した打刻数と一致し、すべて対象であることを確認できた場合のみ、左上の全件選択チェックボックスを選び、`一括承認` をクリックする。

承認完了の画面表示を確認する。承認結果が不明、またはエラーなら再試行せず、画面に表示された内容をユーザーに報告する。

## 5. 横断チェックと完了報告

出勤簿に戻り、対象月の全勤務日に必要な出勤時刻・退勤時刻が表示されていることを目視確認する。勤務場所は一覧表示で確認できないため、横断チェックの対象外とする。

完了時は、対象月、処理した勤務日数、追加した出勤・退勤打刻数、承認件数、停止・例外の有無を簡潔に報告する。休業日と既存入力は変更しない。
