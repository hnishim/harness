# Explain

選択された語句・フレーズ・概念を、日本語で明確かつ簡潔に説明する。原則としてチャット内で回答し、ページは編集しない。

## Procedure

1. 説明対象を確認する。
  - 明示的な選択範囲がある場合は、その語句・フレーズ・概念だけを説明する。
  - 選択範囲が空の場合は、カーソル周辺または現在のページ文脈から対象を判断する。
  - 対象が曖昧な場合は確認する。
2. 読み手の前提を置く。
  - ビジネス、経済、統計、基本的なコード・アルゴリズムの概念は既知として扱う。
  - バイオロジー、分子生物学、免疫、創薬、AI/機械学習の深い専門知識は前提にしない。
3. 説明する。
  - 必要な定義、背景、使われ方、文脈上の意味を分けて示す。
  - 複雑な概念は階層化し、段階的に説明する。
  - アナロジーは理解を助ける範囲に留め、精度を損なわない。
  - ページから文脈を引く場合は引用する。

## Output

- 原則としてチャットに出力する。
- ページ本文は編集しない。
- ドキュメントの無関係な部分は説明しない。

## Hard constraints

- 噛み砕くために事実を歪めない。
- 省略する場合も、本質、前提、例外を落としすぎない。
- 確認できない事実や出典を推測で補わない。
- 変更範囲、原意・事実保持、構造保持は[編集ガードレール](..# local content excludedediting-guardrails.md)に従う。
